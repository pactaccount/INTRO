# AI project proof index

Use two or three projects that match a role. Each evidence page states the problem, engineering approach, measured results, local and hosted checks, limits, and safe résumé wording. A GitHub evidence page is the stable link to put on a résumé; add a live demo link beside it only after the complete public workflow passes.

## Role-specific selections

- **Applied AI / multimodal:** MomentFlow, then SeaQL or Financial RAG after their evaluations are complete.
- **Computer vision / ML:** Argus, then U-Net after checkpoint and held-out Dice/IoU are available; MomentFlow is another strong second project.
- **Agents / workflow:** SeaQL, MedBot, or Robin based on the job, with their current proof limits stated. MomentFlow remains the strongest measured project.
- **Inference / ML systems:** LLM Edge Deployment after a CUDA benchmark, plus MomentFlow or Argus for current measured engineering evidence.

The word “impact” in these demos means measured benchmark or task outcome. None of these artifacts establish customer adoption, revenue, cost savings, clinical benefit, or factory deployment.
